## 🎯 Tool Categories

### 🪪 ID Card Tools
Convert various official documents to PVC cards:
- **PAN Card → PVC**
- **Aadhaar Card → PVC**
- **Voter Card → PVC**
- **Ayushman Card → PVC**
- **Ration Card → PVC**
- **Driving License → PVC**
- **Passport / ID Card → PVC**

**Specifications:**
- Standard size: 85.60 × 53.98 mm
- DPI: 300 (high quality print)
- Pixel dimensions: 1011 × 638 px

### 📸 Photo Tools
Professional photo processing and formatting:
- **Passport Photo Maker** (3×3 cm, 3.5×4.5 cm, custom sizes)
- **Multiple Photos Layout** (A4, 4×6)
- **Background Whitening**
- **DPI Options:** 150 / 300 / 600

### 📄 PDF Tools
Comprehensive PDF manipulation:
- **PDF ↔ JPG Conversion**
- **PDF Merge & Split**
- **PDF Compress**
- **A4 Printable Conversion**

### 🖨️ Printing Tools
Professional printing layouts:
- **A4 Photo Layout**
- **4×6 Photo Layout**
- **Passport Photo Sheet**
- **PVC Card Sheet**

### ✍️ Signature Tools
Signature processing and management:
- **Signature Resize & Crop**
- **Photo + Signature Maker**
- **Application Form Preparation**

### 📑 Document Tools
Document processing and enhancement:
- **Scan Cleanup**
- **Document Crop**
- **Black & White Conversion**
- **Document Compression**

### ⭐ Frequently Used Tools
Quick access: PAN PVC | Voter PVC | Passport Photo | PDF Merge | Print Layout
